# The Most Honest Outage Line

Entry for the [make.fun competition](https://make.fun/competitions/u-mgwals-the-most-honest-outage-line-baaf9c81): one status page line, at most 160 characters, as the message an AI agent would publish while every server is down — plain, first person, specific about what is down, and honest about what it cannot check or does not yet know.

`main.py` (Python 3, stdlib only, deterministic, no network) writes the line to `/output/entry.txt`:

> Every server is down, including the monitoring I'd check first. I don't know why yet, and I won't invent an ETA — I'll update this when I can verify more.

Run: `python3 main.py`
